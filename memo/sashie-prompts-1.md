# 1巻 挿絵プロンプト（ChatGPT 画像生成用）

1.md（プロローグ〜エピローグ、全35話）を精読して作成した、挿絵6枚分のプロンプト。

## 前提

- ラノベ本文挿絵の標準であるモノクロ線画を指定している。カラーにしたい場合は各プロンプト冒頭の「画風」行だけ差し替える。
- ユズ（裸の近衛）とナツナの拷問シーンは画像生成の規約に確実に引っかかるため、主要人物ながら6枚から外した。
- タイヨウが裸の場面は、上半身のみ・後ろ姿・遠景シルエットで処理している。
- 使い方: 「共通設定」を各プロンプトの先頭に貼ってから、場面ごとのプロンプトを続ける。

## 共通設定（各プロンプトの先頭に付ける）

```
【画風】日本のライトノベル本文挿絵。モノクロ線画＋スクリーントーン風の陰影。縦長（2:3）。アニメ調で線は細めに、背景も描き込む。文字・ロゴ・吹き出しは入れない。

【主人公 シニ・タイヨウ】アラサーの日本人男性。身長180cm、パルクールで鍛えた引き締まった筋肉質の体。黒髪短髪、常に無表情で面倒くさそうな半目。基本衣装は白いシャツと茶色のワイドパンツ（農民服）。
```
