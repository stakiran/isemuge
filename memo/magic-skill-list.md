## 補足メモ

### 名称の揺れ・同一物とみられるもの
- **強制貫通《フォース・ペネトレート》** … 第４８話では「フォース・ペネトレレーション」表記
- **空気の壁《エアウォール》** … 第１７３話では「空中壁《エア・ウォール》」表記
- **圧《オーラ》** と **威圧《オーラ》** … 同一の概念
- **シャッフル** … ライムのものは室内、カーディナルのものは建物内部構造で、いずれも「テレポート先として使えなくする」用途
- **記憶の瞬間保存《スナップショット》** … 第４２話に「スナップショッター」という別称の言及あり
- **オープン／ナッツ／ファイア** … いずれもシニ・タイヨウのリリース発動に関わる詠唱・別名の系統

### 対象から除外したもの
- 職業・階級名（闘者《バトラー》、娼者《プロスター》、攻撃魔法師《アタックウィザード》、魔法師《ウィザード》など）
- 種族名（鳥人《ハーピィ》、綿人《コットンマン》、隠密蝸牛《ステルスネイル》など）
- 制度・施設名（出張性交教育《セックラス》、国民時刻表《ワールドスケジュール》、交易区域《コマースゾーン》など）
- 主人公が前世知識や冗談で口にしただけの造語（回復魔法《ヒール》など、「この世界の呼称ではない」と明言されるもの）

### 数え方について
- 「ウルトラ・○○・ソード」（第３８４話）は八属性それぞれの詠唱が存在するが、同系統として１行にまとめた
- ブーガの拷問技（第２１２話）は個別名が列挙されるのみのため１行にまとめた
