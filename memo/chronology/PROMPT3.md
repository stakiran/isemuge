# Phase 3 年表執筆エージェント 共通指示書

Phase 1 で全410話の素データ（`raw/*.md`）、Phase 2 で話ごとの日付（確定済み）が揃いました。
あなたの仕事は、**日付ごとに出来事をまとめた年表の一区画を書くこと**です。

**原稿本体（`1.md`〜`10.md`）は読まないでください。** 指示された `raw/*.md` だけを読みます。
**日付はあなたが決めるのではなく、プロンプトで与えられた対応表に従ってください。**

## 暦

- 1週＝10日、1年＝300日、月という単位は無い
- `第三週二日目《サン・ニ》` と書き、短縮形は `3-2`

## 出力フォーマット

日付ごとに1セクション。**日付の昇順**に並べる。

```
## 3-2 第三週二日目《サン・ニ》

- **該当話**: 第199話〜第200話（5.md）
- **場所**: 学園／貧民エリア
- **人物**: タイヨウ, ルナ, ヤンデ, スキャーノ
- **出来事**:
  - 午前10時前 タイヨウとルナが二対二の模擬戦に臨む
  - 昼 ヤンデが……
  - 夜 ……
- **備考**: 第200話は同時刻のルナ視点
```

書き方の決まり：

- `出来事` は**時間帯順**に並べる。時間帯がわかるものは行頭に `朝` `午前10時前` `昼` `夕` `夜` `深夜` と付ける。わからないものは付けない
- 出来事は raw の `出来事` 欄をもとに、**その日に何が起きたか**が一読でわかる粒度にまとめる。話ごとの箇条書きをただ転記するのではなく、同じ日のものを統合して整理する
- 複数の視点・場所が並行する日は、`出来事` の中で場所や人物がわかるように書く
- `備考` には、回想・行間・同時刻の別視点・日付が `要確認`/`不明` である旨を書く。無ければ `備考` 行ごと省く
- **日付が `要確認` や `不明` の話も必ずどこかに登場させること。** 該当する日のセクションに `備考` 付きで入れるか、その区画の末尾に `## 日付未確定` セクションを作ってまとめる

## 厳守事項

1. **担当範囲の全話を1つも落とすな。** 最後に、書いた話番号を数えて指定数と一致するか確認する
2. **与えられた日付対応表を書き換えるな。** 疑問があれば `備考` に書く
3. **raw に無いことを書くな。** 創作・推測で出来事を足さない
4. 出来事は事実のみ。感想・評価・解釈は書かない
5. 見出しレベルは `##`（日付）と、その下の箇条書きだけを使う。`#` は使わない
