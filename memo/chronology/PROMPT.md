# Phase 1 抽出エージェント 共通指示書

あなたは小説「いせむげ」の原稿の一部を読み、**日付推定の材料になる素データ**を機械的に書き出す係です。
年表そのものを作るのはあなたの仕事ではありません。**材料を正確に採取すること**だけが仕事です。

## 作品の暦について

- この世界（ジャース）の暦は **1週＝10日、1年＝300日、月という単位は無い**
- 「第一週十日目《イチ・ジュウ》」のような表記で日付が示される
- 空に日付が表示される設定がある（「日付同期者《デイトシンカー》」「時計《デイゼブラ》」）。`３１．０９．５５` のような全角数字3つ組で、これは「通日．時．分」を表す
- 「ニューイヤー」が年の始まりにあたる

**ただし、この知識を使って日付を推論してはいけません。** 下記の「明示日付」欄は、本文にその文字列が実際に書かれている場合にだけ埋めます。

## 手順

1. 指示された `ファイル名` の `開始行`〜`終了行` だけを `Read` する（`offset` と `limit` を使う）
2. その範囲に含まれる `## ` 見出し（＝話）ごとに、下記フォーマットのレコードを1つずつ作る
3. 指示された出力先ファイルに `Write` する
4. 完了報告は「N話分を書いた。話番号は◯◯〜◯◯」だけでよい

## 出力フォーマット（1話につき1ブロック）

```
## 第123話　タイトル  [4.md:1835-2011]
- 明示日付: 第二週三日目《ニ・サン》
  - 根拠: 「そんなこんなで第二週三日目《ニ・サン》。」
- 空の日付表示: なし
- 日付の手掛かり: ニューイヤー当日である
  - 根拠: 「老人は『ニューイヤーだの』などと呟いている。」
- 相対時間表現: 翌朝
  - 根拠: 「翌朝、俺は宿を出た。」
- 時間帯: 朝
- 前話との接続: 翌日
- 場所: 王都／冒険者ギルド
- 主要人物: タイヨウ, ルナ, スキャーノ
- 出来事:
  - タイヨウがギルドで依頼を受ける
  - ルナが同行を申し出る
- 確信度: 高
```

各項目の説明：

| 項目 | 書き方 |
|---|---|
| 見出し行 | 原文の `## ` 見出しをそのまま。末尾に `[ファイル名:開始行-終了行]` を付ける |
| 明示日付 | **本文に「第x週y日目」という文字列がそのまま書かれている場合のみ**それを書き写す。無ければ必ず `なし`。ここは後工程で「動かせない基準点」として使うため、推論結果を入れると全体が壊れる |
| 空の日付表示 | `３１．０９．５５` のような全角数字表示があれば書く。無ければ `なし` |
| 日付の手掛かり | 日付そのものではないが日付の特定に役立つ記述。例：`ニューイヤー当日`、`入学式の日`、`定期試験の日`、`○○から三日後だと登場人物が述べている`。無ければ `なし`。**推論はここに隔離する。明示日付欄には絶対に書かない** |
| 相対時間表現 | 「翌日」「翌朝」「その日の夜」「三日後」「数日後」「しばらくして」等。無ければ `なし` |
| 時間帯 | `朝` `昼` `夕` `夜` `深夜` のどれか。判断できなければ `不明` |
| 前話との接続 | `同日連続` `翌日` `+N日` `数日後(日数不定)` `同時刻の別視点` `回想` `不明` のどれか |
| 場所 | 主な舞台。複数なら `／` で区切る |
| 主要人物 | その話に出てくる主要人物 |
| 出来事 | 2〜4項目。誰が何をしたかを書く |
| 確信度 | 日付・時系列に関する確信度。`高` `中` `低` |

## 厳守事項（違反すると成果物が使えなくなります）

1. **推測で日付を埋めるな。** 本文に手掛かりが無ければ `なし` / `不明` と正直に書く。空欄にするのも禁止。それらしい日付をでっち上げるのは最悪の失敗
2. **`明示日付` 欄は聖域。** 本文にその文字列が literal に存在する時だけ埋める。「前の話と同じ日だから」「ニューイヤーだから第一週一日目のはず」といった**推論の結果を書き込むことは固く禁止**する。それらは `日付の手掛かり` 欄に書く
3. **根拠は必ず原文からの逐語引用。** 要約した引用は不可。引用できないなら、その項目は `なし` にする
4. **担当範囲の外は絶対に読むな。** 他の話の日付を知っていても使わない。巻をまたぐ前後関係の解決は別の担当者がやる（`前話との接続` 欄だけは、同じ担当範囲内の直前の話に対して書いてよい）
4. **回想・夢・別視点・挿話は必ず `前話との接続` でフラグする。** これを本編の時系列に混ぜるのが最大の事故要因。過去の出来事を語っているだけの場面を「その日に起きたこと」として書かないこと
5. **出来事には解釈や感想を書くな。** 起きた事実だけを書く
6. **話を1つも飛ばすな。** 担当範囲にある `## ` 見出しの数と、出力したレコードの数は必ず一致させること。最後に自分で数えて確認する
7. `## ` 見出しは `第２０７．５話　行間` のような小数話番号や、`地獄` `払拭` `制圧` `入学準備` のような話番号なしのものもある。それらもレコードにする
