# 弱点三点の詳細 — 設定講義・性描写・固有名詞

`memo/fullscan-omoshirosa.md` で挙げた三つの弱点について、作者の反論（設定は世界観の魅力／性描写はラノベのテンプレ／固有名詞は説明とルビで対応済み）を受けての詳細分析。

## 前提

42体のスキャンエージェントは互いの報告を見られない状態で走った。にもかかわらずこの三点が独立に何度も挙がった。一人の評者の好みではなく、**再現する構造**である。

ただし再現したのは「設定・性描写・固有名詞があること」ではない。そこは切り分けが要る。

---

## 1. 設定講義 — 「世界観の魅力」は正しい。問題は提示モード

### 1.1 まず認めるべき点

世界観そのものは本作の武器である。エージェントたちが自発的に褒めた設定は多い。

- 「まるで観測した時に状態を決める量子のように」（6巻・防御力の理屈）
- ジオグライト＝石で書き、視覚でなく空間認識で読む（9巻）→「SF的ガジェット発想」と評価
- レベルが強さだけでなく**倫理・婚姻・死罪の基準**にまで浸透している（8巻）
- 板一枚が異常に高い→「国は一般人のレベルアップを促している。わざと貧乏な世界観を構築することによって」（7巻）

最後の一つが決定的である。**同じ「経済設定の説明」でも、これは停滞していない。**

### 1.2 機能する設定 vs 停滞する設定 — 分岐点は「賭け金」

| 設定 | 出し方 | 結果 |
|---|---|---|
| 板の価格（7巻） | 主人公が**推理して気づく** | 世界が仕組まれている恐怖に転化 |
| 隠しステータス「基礎」（9巻） | 「なぜか強い」の**積み上げの回収** | カタルシス |
| 隠しステータス「反応」（2巻） | ブーガが**戦闘中に看破** | 敵の格の証明 |
| 詠唱の文法（複数巻） | → **サンナッツ**で使う（8巻） | ルール説明そのものが伏線 |
| 種族間協定の分類（2巻 4237-4266） | 誰かが誰かに教える | 停滞 |
| 多段ゲート（2巻 4487-4499） | 同上 | 停滞 |
| ダグリンルール・外府・国民時刻表（4巻） | 会議で列挙 | 停滞 |
| チャームの仕組み（6巻・温泉） | 同上 | 停滞 |
| オブリージュ・ジェネライゼーション（10巻） | 密談で説明 | 停滞 |

判定基準は一つ。

> **「その情報を知らないと、次の場面で何が起きるか読者にわからない」か。**

Yes なら設定は物語。No なら設定資料。同じ密度・同じ長さでも読者の体感が変わる。

### 1.3 具体的な症状：質問役が「無知なだけ」になっている

2巻の竜人パートについてのエージェント評——

> リューネの無知setup（「誰です？」の繰り返し）による説明台詞が長く、ギャグとしてはやや冗長

会話体にすれば講義でなくなるわけではない。**質問する側が、答えを聞いても何も得ないし何も失わない**構図だと、それは会話の形をした地の文である。

5巻のハナの政治理念の長台詞も同型。エージェント評は「地の文での要約に留めた方がテンポが良かった」。

### 1.4 結論

「世界観の魅力として書いている」は正しい。ただし**魅力として効いているのは、賭け金のある出し方をした分だけ**。上表の下半分は、内容が悪いのではなく、置き場所と話者の設計が違う。設定を削れという話ではない。

### 1.5 該当箇所リスト（全巻）

- 1巻：階級社会・国情の解説、輪廻転生の理屈、グラフ理論の講釈（3〜4段落）
- 2巻：警察制度・QoL議論、種族間協定の分類、多段ゲート、近衛ユズとの労働契約説得
- 3巻：校舎の「ロ」の字構造、暦の説明、デバッグモード／LSRW自動翻訳フラグ考察（4457〜4890）、チャーム体質の講釈
- 4巻：ダグリンルール、外府、国民時刻表、アンサールート、交渉パート（8280〜8722）
- 5巻：ハナの政治理念、ラウルのブーガ論、貧民エリア経済活性化、エルフ階級・呼称設定
- 6巻：試験レベル判定の理屈、温泉でのチャーム説明、レベル・防御力のロジック考察

## 2. 性描写 — 「テンプレだから」で通せない箇所がある

三つに分ける。二つは反論が通り、一つは通らない。

### 2.1 反論が通る部分

量そのものは、ジャンル水準として異常ではない。ここは同意する。

### 2.2 通らない部分① — 本作固有の構造的ハンデ

主人公は**バグにより不能・無感情**である。これは作者が自ら設定した最大の縛りで、本作の魅力の中心でもある。しかしこの設定は、性描写から**通常のペイロードを奪う**。

普通のラノベなら性描写は「主人公の欲望」「関係の進展」を運ぶ。本作の主人公はどちらも運べない。だから本作の性描写は、代わりに**ギャグか情報のどちらかを運ばないと空になる**。

**運べているとき（機能している）**

- 5巻「不能確認」イベント → 演技の巧拙を楽しむメタコメディに転化
- 5巻「要するに、元気な俺でお邪魔するという、本来の意味での行為ができなかったのだ」→ 無敵と不能の表裏
- 9巻 アキナの「授乳吸収」→ 実は隠しステータス鑑定。情報を運んでいる

**運べていないとき**

- 9巻、ハンティ×スキャーナ／マーシィ×職員／ミーシィ×マーシィが**近接して三連続**
  - エージェント評「同工異曲でパターンが似ているため新鮮味がやや薄れる」
- 5巻「女牧場」開宴パート
  - エージェントは**着想を褒めている**——「蹂躙される哀れな被害者ではなく、統率された不気味な集合知性として描くことで凌辱ものテンプレを反転させている」
  - そのうえで「同種の凌辱描写の反復により中盤で単調」
  - **アイデアは勝っていて、尺で負けている**

つまり問題は「テンプレを使ったこと」ではなく、**主人公設定がテンプレの効能を無効化しているのに、テンプレの分量で書いている**こと。これは他作品からは輸入できない、本作固有の会計である。

### 2.3 通らない部分② — 7巻284話（カレンへの性暴力）

**ここはラノベのテンプレではない。** 本項の本題。

構造上の機能ははっきりしている。カレンの強かさ（襲われながら相手の呼吸依存という弱点を分析している）と、主人公の非情さを同時に証明する。

> 「（気にしない気にしない）／俺は何も知らぬし存ぜぬ。」（7巻 5865行）

この機能は認める。むしろ主人公の冷徹さを一行で刻んだ名場面である。

問題は二つ。

1. **機能に対して描写量が過剰**
   - エージェント評「物語上の機能は理解できるが、必然性の薄い描写量に感じられる」
2. **直後に285〜286話の性欲講義（喜劇的な下ネタパート）が来る**
   - 同じ題材が、数話の間に**暴力の register からギャグの register へ無断で移動する**
   - 読者は前の場面をどう処理していいかわからなくなる

「シリアスと下ネタの等価並置」は本作の芸であり、論考では長所として書いた。**主人公の無感情がそれを正当化しているから**である。

しかしこの一箇所だけは、主人公が観測していない場面で起きている。等価並置を支える語りの根拠がない状態で、並置だけが起きている。

ここは「ラノベのテンプレ」という枠で守れる場所ではない。

## 3. 固有名詞 — ルビが解決するのは四つのうち二つ

ルビが解決するのは **①読み・②意味**。優秀に機能している。「｜賭けている《ベットしている》」「｜処刑の参考《リファレンス・トライ》」あたりは、説明抜きで概念を通す技として上手い。

しかしルビが解決しないものが二つある。

### 3.1 ③陣営（誰が誰の味方か）

3巻108-109話へのエージェント評——

> デミトト・ラウドウルス・廃戦協定など固有名詞が多く、**初読では誰が誰の陣営か把握しづらく**、やや情報過多

ルビは語の意味を教えるが、**関係を教えない**。本作は10巻かけて 4国＋ギルド＋法国＋竜人＋モンスター勢力の多極構造を作った。読者が迷うのは「その単語の意味」ではなく「その人物がどっち側か」である。

### 3.2 ④重要度（覚えるべきか、流していいか）

全固有名詞が**同一の様式でルビを振られる**ため、後で効いてくる名前と使い捨ての名前が視覚的に区別できない。読者は全部を等しく覚えようとして疲弊するか、全部を等しく流して伏線を落とすかの二択になる。

### 3.3 これは名前の問題ではなく、置き場所の問題

エージェントが挙げた箇所を並べると明確な偏りが出る。

| 巻 | 箇所 | 内容 |
|---|---|---|
| 1 | 35話（巻末群像） | 鳥人の王、アングリ、教皇、ブーガが立て続け |
| 2 | 51-52話 | シャーロット、アングリ、プロテス、アナバ、ラウル、アウラを短時間に大量投入 |
| 3 | 108-109話 | デミトト、ラウドウルス、廃戦協定 |
| 5 | エピローグ | チッチ、キューピン、ナタリー、カーディナルが一気に |
| 8 | 将軍会議 | 政府経済統括・軍部冒険統括…の役職羅列 |
| 9 | 339-344話「各勢力1〜6」 | マスタークラス、カーディナル、コアレス |
| 10 | 206-400行 | ハナ、ガーナ、ミーシィ、レコンチャンが一気に |

**全部、群像回・行間回・エピローグである。** 主人公視点の場面では問題が出ていない。そこでは固有名詞が一つずつ、主人公のリアクションを伴って登場するからだ。

症状は「固有名詞が多い」ではなく、**「主人公の視点フィルタを外した場面で、初出が同時多発する」**。

## 4. 三つは同じ一つの問題である

並べると気づく。

- 設定講義の停滞 → 群像回・会議シーン・章の切れ目
- 使われない性描写 → 章の切れ目、緊張の直後
- 固有名詞の氾濫 → 群像回・行間回・エピローグ

**同じ場所に出ている。**

主人公視点の本編は、一人称のツッコミという強力なフィルタが常に働いていて、情報も下ネタも固有名詞も、必ず「主人公の反応」を経由して読者に届く。だから消化できる。

視点を離れた瞬間、そのフィルタが消える。そこに、フィルタありの本編と同じ密度で情報を流している。これが三症状の共通原因。

### 補足：多視点構成を廃止する話ではない

本作の多視点構成は**最大の武器**である。倒叙ミステリの多重推理（ヤンデは体質から、ミーシィはベーサイトから、フレアは日本語のメモから、スキャーナはキスへの偏重から、それぞれ独立に同じ真実へ収束する）は、これなしには成立しない。

必要なのは、視点を離れた場面に**別の減圧装置**を置くこと。読者の代弁者になる無知キャラではなく、**利害を持った当事者**である。

成功例：9巻のナナ。カウンセリングと称して弱点を探ろうとした一般人職員が、主人公の得体の知れなさに耐えきれず嘔吐する。

> 「一体何なの。《《コイツ》》は一体何？」（9巻）

情報が「彼女が壊れていく過程」として運ばれているので、まったく停滞しない。これが視点外パートの理想形。

---

## 5. 重みづけ

この三点は**本作の評価を脅かす規模ではない**。10巻を通した弱点の重みは、

> 未回収の根本設定（無敵バグ・滅亡バグ・天使・輪廻） ≫ 上記三点

三点は読書体験の摩擦であって、作品の企図を損なってはいない。

作者の反論のうち「設定は世界観の魅力」はほぼ全面的に正しく、「固有名詞に説明とルビを入れている」も対策として実際に効いている。残余は本文書に書いた分だけである。

「性描写はラノベのテンプレ」だけは、7巻284話に関して成立しない。
